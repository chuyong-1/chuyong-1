## Hi, I'm Chuyong

AI engineer intern building multi-agent systems and LLM apps that are safe to run in production. My rule of thumb: **the model proposes, deterministic code decides.**

- **Now:** AI Software Engineer Intern at **FreighAI**, and AI Developer Intern at **Banao Technologies** (since Jan 2026), where I work on **AXON**, a multi-agent meeting intelligence and workforce orchestration platform. I own its data pipelines, ingestion, and the NERVE agent (event bus + scheduler).
- **Studying:** B.Tech in Computer Science (AI & ML), Manipal University Jaipur, 2024–2028
- **Interested in:** multi-agent design, LLM guardrails, local-first / offline AI, AI benchmarking, financial data pipelines

### Featured projects

|---|---|---|
